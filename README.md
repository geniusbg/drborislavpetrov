# 🏥 Д-р Борислав Петров - Стоматологична клиника

## 📋 Описание

Модерно уеб приложение за управление на стоматологична клиника с административен панел, резервации, потребители и анализи.

## 🚀 Функционалности

### 👨‍⚕️ Административен панел
- **Резервации**: Управление на резервации, търсене, сортиране, пагинация
- **Календар**: Визуализация на резервациите по дати
- **Потребители**: Управление на пациенти, история на резервации
- **Услуги**: Управление на стоматологични услуги
- **Анализи**: Статистики и отчети
- **Настройки**: Работно време, защита от ботове

### 📱 PWA функции
- **Offline поддръжка**: Работа без интернет връзка
- **Инсталиране**: Инсталиране като нативно приложение
- **Push notifications**: Известия за резервации
- **Background sync**: Синхронизация при връщане на връзката

### 🎤 Гласови команди
- **Siri Shortcuts**: Интеграция с iOS Siri
- **Гласов интерфейс**: Управление чрез глас
- **Гласов асистент**: Интелигентен асистент

## 🏗️ Архитектура

### 📁 Структура на проекта
```
src/
├── app/                    # Next.js App Router
│   ├── admin/             # Административен панел
│   ├── api/               # API endpoints
│   └── layout.tsx         # Главен layout
├── components/             # React компоненти
│   ├── admin/             # Административни компоненти
│   └── ui/                # UI компоненти
├── contexts/              # React Context
├── hooks/                 # Custom React hooks
├── lib/                   # Утилити и библиотеки
├── types/                 # TypeScript типове
└── styles/                # CSS стилове
```

### 🔧 Технологичен стек
- **Frontend**: Next.js 14, React 18, TypeScript
- **Styling**: Tailwind CSS
- **Database**: PostgreSQL
- **State Management**: React Context API
- **Offline**: IndexedDB, Service Worker
- **Real-time**: WebSocket (Socket.io)
- **Authentication**: JWT tokens

## 🚀 Инсталация и стартиране

### Предварителни изисквания
- Node.js 18+
- PostgreSQL 14+
- npm или yarn

### Стъпки за инсталация

1. **Клониране на проекта**
```bash
git clone <repository-url>
cd drborislavpetrov
```

2. **Инсталиране на зависимости**
```bash
npm install
```

3. **Настройка на базата данни**
```bash
# Създай PostgreSQL база данни
createdb drborislavpetrov

# Настрой connection string в .env.local
DATABASE_URL="postgresql://user:password@localhost:5432/drborislavpetrov"
```

4. **Настройка на environment променливи**
```bash
cp .env.example .env.local
# Редактирай .env.local с твоите настройки
```

5. **Стартиране на приложението**
```bash
npm run dev
```

6. **Отваряне в браузъра**
```
http://localhost:3000
```

## 🔧 API Endpoints

### Административни endpoints
```
GET    /api/admin/bookings          # Всички резервации
POST   /api/admin/bookings          # Създаване на резервация
PUT    /api/admin/bookings          # Обновяване на резервация
DELETE /api/admin/bookings          # Изтриване на резервация

GET    /api/admin/users             # Всички потребители
POST   /api/admin/users             # Създаване на потребител
PUT    /api/admin/users             # Обновяване на потребител
DELETE /api/admin/users             # Изтриване на потребител

GET    /api/admin/services          # Всички услуги
POST   /api/admin/services          # Създаване на услуга
PUT    /api/admin/services          # Обновяване на услуга
DELETE /api/admin/services          # Изтриване на услуга

GET    /api/admin/daily-schedule    # Дневен график
POST   /api/admin/daily-schedule    # Обновяване на график
```

### Публични endpoints
```
GET    /api/bookings                # Публични резервации
POST   /api/bookings                # Създаване на резервация
GET    /api/services                # Публични услуги
```
